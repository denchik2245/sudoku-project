# Sudoku REST API Project

## Описание проекта

Данный проект представляет собой backend + web UI приложение по теме **Sudoku**, реализованное в формате **REST API** с поддержкой асинхронной обработки фоновых задач.

Система позволяет:

- генерировать новые Sudoku-поля;
- решать Sudoku;
- проверять корректность игрового поля;
- создавать и сохранять игры;
- выполнять игровые ходы;
- использовать кэширование через Redis;
- использовать брокер сообщений RabbitMQ для фоновых задач;
- работать через веб-интерфейс.

## Архитектура проекта

Проект состоит из следующих компонентов:

### 1. Backend API
REST API на FastAPI, который:
- обрабатывает HTTP-запросы;
- работает с бизнес-логикой;
- взаимодействует с БД;
- использует кэш;
- публикует фоновые задачи в очередь.

### 2. Sudoku Engine
Отдельный модуль логики Sudoku:
- генерация полей;
- валидация;
- решение.

### 3. Database Layer
PostgreSQL используется для хранения:
- игр;
- ходов;
- фоновых задач.

### 4. Cache Layer
Redis используется для:
- кэширования результатов генерации Sudoku;
- кэширования результатов решения одинаковых полей.

### 5. Message Broker
RabbitMQ используется для:
- постановки задач в очередь;
- асинхронной генерации Sudoku;
- асинхронного решения Sudoku.

### 6. Worker
Отдельный worker-процесс:
- слушает RabbitMQ;
- обрабатывает задачи;
- обновляет статус задач в БД.

### 7. Web Interface
Веб-интерфейс реализован через FastAPI + Jinja2 templates и позволяет работать с проектом через браузер.
